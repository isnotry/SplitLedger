## 它是什么

一个极简的**记账 + AA 分摊**小工具。不注册、不登录、不上传 —— 数据只存在你自己浏览器的 `localStorage` 里。

网页端是**一个单文件**（`web/index.html`，HTML / CSS / JS 全部内联），零依赖、零构建、零后端，双击就能用，也能随手丢到任意静态托管上。

## 特性

- **极简记账** —— 每行一条，像发消息一样写：`午饭 18`、`打车 23.5`、`报销到账 +120`
- **智能识别** —— 取每行**最后一个数字**作为金额，其余文字当摘要；支持支出 `-6`、收入 `+120`、千分位 `1,200`、小数 `59.9`、全角数字、结尾的「元 / 块 / ¥」
- **没数字的行不丢** —— 原样保留展示，只是标注「不计入」合计
- **实时统计** —— 合计（净额 = 收入 − 支出）、收入、支出、笔数、未识别行
- **保存与记录** —— 一键把编辑区拆成逐条记录（新批在前），可单条删除、可清空
- **AA 结算** —— 填上「TA 已付」，自动算清谁该给谁，并把四步算式摊开给你看
- **两种导出** —— 长图（`⌘/Ctrl + S` 或菜单）与 CSV
- **中英双语** —— 右上角国旗一键切换，币种跟着语言走（`¥` / `$`）
- **自动跟随系统深色模式**，响应式布局（600px / 860px 断点）

## 记账规则

每行取**最后一个数字**作为金额，`+` 是收入、`-` 是支出，**不带符号的数字**按工具栏「无符号数字算作」的设置处理（默认算支出）。

| 你写的 | 识别为 | 说明 |
| --- | --- | --- |
| `午饭 18` | 支出 ¥18.00 | 无符号，按工具栏设置算支出 |
| `打车 23.5` | 支出 ¥23.50 | 支持小数 |
| `报销到账 +120` | 收入 ¥120.00 | `+` 开头算收入 |
| `客户打款 +1,200` | 收入 ¥1,200.00 | 支持千分位 |
| `买菜 １２` | 支出 ¥12.00 | 支持全角数字 |
| `买牛奶 59.9 元` | 支出 ¥59.90 | 结尾的「元 / 块 / ¥」会被忽略 |
| `今天忘了带钱包` | — | 没有数字：保留展示，标注「不计入」 |

## AA 结算怎么算

口径是：**账本里记的是「我」付的钱，「TA 已付」那部分手填；两者都算进共同开销，再按两人平摊。**

```
你的净垫付  mine  = 支出 − 收入
合计已付    total = mine + TA 已付
每人应承担  each  = total ÷ 2
差额        diff  = each − TA 已付     （恒等于 (mine − TA 已付) ÷ 2）
```

- `diff > 0` → **TA 需付给你**（绿色）
- `diff < 0` → **你需付给 TA**（红色）
- `TA 已付 == 你的净垫付` → **两清**，只显示文字不显示金额（差值小于 0.005 视为两清，避开浮点误差）

## 数据与隐私

- 数据**只存本机浏览器**，不上传、不联网、无账号。换浏览器或清缓存 = 换一本账。
- 存储位置（`localStorage`）：

| Key | 内容 |
| --- | --- |
| `ledger-mini/v1` | 草稿：编辑区文本、方向设置、语言、AA 结算的「TA 已付」 |
| `ledger-mini/saved/v1` | 已保存记录，逐条 `{at, label, amount, dir}` |

> Key 前缀保留 `ledger-mini` 是**故意**的：改了等于所有老用户的账本清零。

## 开发说明

- 网页端**没有构建、没有依赖**：改完 `web/index.html` 刷新浏览器即可。
- 中英词条在同一个 `I18N` 对象里（`zh` / `en`），两份 key 必须**严格对齐**，改文案两边同步。
- 导出的长图最多画 200 行明细，超出会在图尾标注「另有 N 条未在图中显示」。

## 浏览器支持

Chrome / Edge / Safari / Firefox 等现代浏览器。导出长图基于 Canvas，已针对 iOS Safari 的画布面积上限做降采样兜底；导出失败时会提示换个浏览器重试。
